## Spoti-clone - Spotify Clone Music Player with embedded AI for Music Suggestion 🎵🎸

Music app inspired by [Spotify](https://open.spotify.com/) UI-looks (Download .apk demo [here](https://github.com/mikkelofficial7/android-spotify-clone/raw/refs/heads/main/demo-testing.apk))

Apk Supports ```Android 9.0``` to ```Android 15```

[See full video demo](https://github.com/mikkelofficial7/android-spotify-clone/blob/main/video.mp4)

Tech stacks:
- Jetpack Compose Material3 ```1.3.1``` + Coil ```2.4.0```
- Koin Dependency Injection
- AndroidX Room
- Retrofit + OkHttp3
- Broadcast Receiver
- Glide
- Exoplayer + Foreground Service
- google/gemini-2.0-flash-thinking-exp-1219:free (optional AI-Based feature, Free version)

Features:
- Login page,
- Search music/track
- Album detail page
- Add to favorite track
- Create and add playlist
- Player bar button can be used both in app screen or notification playback
